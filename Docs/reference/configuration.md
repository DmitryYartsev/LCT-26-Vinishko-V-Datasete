# Справочник: конфигурация

## Как читается конфигурация

Сервис распознавания читает один YAML — `config/pipeline.yaml` (путь задаёт переменная
`PIPELINE_CONFIG`). Значения из YAML превращаются в переменные окружения до того, как их читает
код, поэтому **источник истины — YAML**, а переменные окружения в `docker-compose.yml` работают
как запасные значения (применяются, только если ключа в YAML нет).

Секции: `paths`, `retrieval`, `ocr`, `csv_match`, `visual`.

## `paths` — пути внутри контейнера

| Параметр | Значение | Смысл |
|---|---|---|
| `prompt_file` | `/app/prompts_wine_match.txt` | промпт для vision-модели |
| `reference_csv` | `/app/ref/found_in_catalog_corrected.csv` | карточки каталога для сопоставления полей |
| `start_photos` | `/app/ref/start_photos` | эталонные фото каталога (визуальная проверка кандидата) |
| `models_dir` | `/app/models` | веса энкодера и детекторов |
| `catalog_ocr_fields` | `/app/ref/catalog_ocr_fields.csv` | поля этикеток каталожных фото, прочитанные моделью заранее |

## `retrieval` — визуальный поиск

| Параметр | Значение | Смысл |
|---|---|---|
| `model` | `${paths.models_dir}/siglip2-base-patch16-256` | откуда загружать энкодер |
| `index_model` | `/app/models/siglip2-base-patch16-256` | ключ модели в таблице векторов: поиск идёт только по векторам с этим ключом |
| `encoder` | `auto` | `auto` \| `siglip` \| `dinov2` |
| `backend` | `local` | `local` \| `remote` (инференс энкодера на другой машине) |
| `crop_enabled` | `true` | искать бутылку детектором и обрезать фон |
| `crop_model` | `${paths.models_dir}/yolo11n.pt` | детектор бутылки |
| `crop_margin` | `0.06` | насколько расширять найденный бокс, доля |
| `crop_min_conf` | `0.25` | порог уверенности детектора бутылки |
| `label_enabled` | `true` | использовать вторую ветку — кроп этикетки |
| `label_model` | `${paths.models_dir}/label_det_best.pt` | детектор этикетки |
| `label_min_conf` | `0.2` | порог уверенности детектора этикетки |
| `label_margin` | `0.02` | расширение бокса этикетки |
| `crop_pick`, `crop_fallback`, `crop_min_area`, `label_pick`, `label_min_w_frac` | `big_center`, `orig`, `0.0`, `conf`, `0.0` | как выбираются боксы при **сборке векторов каталога** |
| `query_crop_*`, `query_label_*` | `big_center_border`, `label`, `0.10`, `0.12`, … | как выбираются боксы для **фотографии пользователя**; пусто — как у индекса |
| `label_align` | `false` | выпрямление этикетки по четырём углам (влияет и на индекс) |
| `pipeline` | `combined` | `combined` — обе ветки, `bottle` — только бутылка, `label` — только этикетка |
| `thresh_score` | `0.81` | верхний порог: от него карточка показывается сразу |
| `thresh_score_lo` | `0.70` | нижний порог: ниже — «вина в каталоге нет» |
| `thresh_margin` | `0.015` | минимальный отрыв первого ответа от второго (справочно) |
| `eval_abstain` | `false` | `true` — эндпоинт оценки возвращает пустой ответ вместо кандидата ниже нижнего порога |
| `top_k` | `6` | длина шорт-листа: и пул кандидатов для чтения этикетки, и длина ответа |
| `database_url` | `postgresql://vino:vino@db:5432/vino` | БД с векторами |

## `ocr` — чтение этикетки внешней моделью

| Параметр | Значение | Смысл |
|---|---|---|
| `enabled` | `true` | `false` — сервис работает только визуальным поиском |
| `model` | `google/gemini-2.5-flash` | модель на OpenRouter |
| `api_key_env` | `OPENROUTER_API_KEY` | имя переменной с ключом (ключ лежит в `.env`) |
| `api_url` | `https://openrouter.ai/api/v1/chat/completions` | адрес API |
| `temperature` | `0.0` | |
| `max_tokens` | `700` | |
| `timeout` | `120` | секунд на один вызов |
| `retries` | `3` | сколько раз повторять при ошибке сети или пустом ответе |
| `min_confidence` | `0.30` | ниже — прочитанные поля не рассматриваются |
| `confirm_confidence` | `0.80` | уверенность, с которой перестановка от модели подтверждает карточку (в рабочем диапазоне порогов) |
| `use_label_crop` | `true` | в модель отправляется выпрямленный кроп этикетки, а не всё фото |
| `label_crop` | `align` | что отправлять: `align` (бокс детектора + выпрямление), `bbox`, `bottle`, `auto` |
| `label_crop_min_conf` / `label_crop_min_area` / `label_crop_max_aspect` | `0.45` / `0.02` / `3.0` | когда бокс считается надёжным (для `auto`) |
| `retry_on_poor_fields` | `true` | повторный проход по кропу бутылки, если прочитано мало полей |
| `min_side` / `max_side` | `800` / `1400` | апскейл мелкого кропа и ограничение размера, px (`0` — не трогать) |

## `csv_match` — сопоставление прочитанных полей с каталогом

| Параметр | Значение | Смысл |
|---|---|---|
| `weights.winery` | `0.15` | вес винодельни |
| `weights.grape` | `0.24` | вес сорта — главный различитель близких вин |
| `weights.color` | `0.15` | вес цвета (красное/белое/розовое) |
| `weights.wine_type` | `0.15` | вес типа (сухое/полусухое/полусладкое/сладкое/брют) |
| `weights.line` | `0.20` | вес линейки/серии |
| `weights.sparkling` | `0.07` | игристое против тихого |
| `weights.year` | `0.02` | год — почти не влияет |
| `weights.additional_text` | `0.02` | прочий текст этикетки |
| `token_thresh` | `0.72` | порог нечёткого совпадения слов |
| `year_only_if_vintage_conflict` | `false` | учитывать год только при конфликте винтажей в каталоге |
| `missing_credit` | `0.5` | оценка поля, которого нет у записи каталога (нейтрально) |
| `min_score` | `0.35` | ниже — совпадение не засчитывается |
| `agree_confidence` | `0.80` | при такой уверенности «модель согласна с поиском» подтверждает карточку |
| `grape_from_text` | `true` | добирать сорт из прочего распознанного текста |
| `grape_contain` | `true` | требовать, чтобы все сорта с этикетки были в записи каталога |
| `fuzzy_ck_norm` | `true` | не различать `ц/к` в названиях сортов |
| `enrichment_file` | `auto` | дополнять записи каталога полями из `paths.catalog_ocr_fields`; `""` — выключить |
| `shortlist_only` | `false` | `true` — сопоставлять только с шорт-листом визуального поиска |
| `decision_margin` | `0.35` | с каким запасом ответ модели вытесняет ответ визуального поиска |

## `visual` — визуальная проверка кандидата

| Параметр | Значение | Смысл |
|---|---|---|
| `enabled` | `true` | сравнивать фото пользователя с эталонными фото каталога |
| `min_similarity` | `0.70` | порог сходства, ниже которого сходство считается низким |
| `block_on_mismatch` | `false` | `true` — запрещать ответ при низком сходстве (по умолчанию это мягкий сигнал) |

## Переменные окружения

| Переменная | Где задаётся | Значение по умолчанию | Смысл |
|---|---|---|---|
| `OPENROUTER_API_KEY` | `.env` | — | ключ OpenRouter: чтение этикеток в `ml`, диалог и речь в сомелье |
| `PIPELINE_CONFIG` | `docker-compose.yml` | `/app/config/pipeline.yaml` | путь к конфигу |
| `SEARCH_MODEL` | `.env` | `/app/models/siglip2-base-patch16-256` | энкодер |
| `SEARCH_ENCODER` | `.env` | `siglip` | тип энкодера |
| `LLM_MODEL` | `.env` (необязательно) | `google/gemini-2.5-flash` | модель диалога сомелье |
| `STT_MODEL` | `.env` (необязательно) | `google/gemini-2.5-flash` | модель распознавания речи |
| `DEBUG_INFO` | `.env` (необязательно) | `0` | `1` — показывать в интерфейсе время поиска и уверенность |
| `PUBLIC_HOST` | `.env` (необязательно) | `localhost` | адрес сайта для HTTPS (нужен микрофон в браузере) |
| `HTTP_PORT`, `HTTPS_PORT` | `.env` (необязательно) | `80`, `443` | порты HTTPS-прокси |
| `EVAL_DIR` | окружение команды | `./eval` | какой набор фото отдавать прогону оценки |
| `EVAL_MAX_TIME` | окружение команды | `300` | таймаут на одно фото при прогоне оценки, секунды |
| `HF_HUB_OFFLINE` | `docker-compose.yml` | `1` | не обращаться в HuggingFace: веса уже скачаны |
